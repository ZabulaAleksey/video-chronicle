# Архитектура

## Назначение

`video-chronicle` — однопроцессное консольное приложение на Python для сортировки, нормализации и объединения фотографий и видео в единый MP4-файл.

## Компоненты

- `join_media.py` — точка входа и вся прикладная логика.
- FFprobe — чтение потоков, метаданных и дат создания.
- FFmpeg — преобразование каждого источника и объединение подготовленных клипов.
- `~/Input` — входной каталог по умолчанию; исходные файлы только читаются.
- временный `video_join_work_*` рядом с результатом — нормализованные клипы и concat-список.

## Поток данных

1. Скрипт находит поддерживаемые медиафайлы во входном каталоге.
2. FFprobe возвращает метаданные и сведения о потоках.
3. Дата выбирается из метаданных или имени файла.
4. FFmpeg приводит каждый элемент к 1600×900, 60 FPS, H.264 и AAC и добавляет дату.
5. Подготовленные клипы объединяются без повторного кодирования.
6. Временный результат атомарно заменяет итоговый MP4; рабочий каталог удаляется, если не указан `--keep-work`.

## Границы

Проект не содержит сервера, базы данных или графического интерфейса. Каталоги `ffmpeg/` и `ffmpeg1/` являются локальными сторонними зависимостями и не входят в историю основного репозитория.
