# Дизайн

У проекта есть переходная одностраничная desktop-оболочка PySide6 и
сохраняется прямой CLI-интерфейс.

## GUI baseline

- одно окно с выбором входной папки и итогового MP4;
- отдельная группа параметров FFmpeg, FFprobe, CRF и preset;
- основное действие «Собрать хронологию»;
- indeterminate progress во время работы, краткий статус и read-only журнал;
- светлая нейтральная поверхность с бирюзовым акцентом, явными focus-состояниями
  и foreground-цветами, не зависящими от светлой или тёмной системной палитры;
- существующий файл требует модального подтверждения;
- элементы настройки блокируются на время процесса;
- закрытие активного окна блокируется с объяснением отсутствия безопасной отмены.

GUI пока не показывает список медиа, порядок, проценты или предпросмотр и не
хранит настройки между запусками.

## CLI

Принципы CLI:

- параметры имеют явные имена и справку `--help`;
- прогресс выводится краткими сообщениями по каждому файлу;
- ошибки отдельных медиафайлов не останавливают всю обработку;
- критические ошибки завершают процесс ненулевым кодом;
- подробности ошибок записываются в `errors.log` рядом с результатом.
