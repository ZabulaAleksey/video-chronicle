# Безопасность и сохранность данных

## Граница доверия

Медиа, метаданные, имена файлов, каталоги проекта, состояние возобновления и
вывод внешних инструментов считаются недоверенными. FFmpeg, FFprobe и другие
опциональные инструменты запускаются как отдельные процессы. Текущий CLI
проверяет их доступность; проверка совместимой версии является обязательным
release gate для будущего пакетирования, но ещё не реализована.

## Инварианты медиаконвейера

- Исходные файлы используются только для чтения и никогда не служат целью
  временного или итогового вывода.
- Внешние программы получают argv-списки; `shell=True` и сборка shell-команды
  из пользовательских путей запрещены.
- Выходной путь проверяется отдельно от входов. Существующий файл нельзя
  заменить без явного разрешения.
- Промежуточные файлы создаются в выделенной рабочей папке. Итог публикуется
  атомарно после успешного завершения и проверки, насколько это поддерживает
  файловая система.
- Очистка ограничена известной рабочей папкой задания и не следует по
  непроверенным ссылкам или путям из кэша.
- Ограничения размеров, длительности, количества файлов и метаданных должны
  срабатывать до неконтролируемого расхода CPU, памяти или диска.
- Диагностика не должна включать секреты окружения или избыточное содержимое
  метаданных; путь допускается показывать только когда он нужен пользователю.
- GUI запускает `sys.executable` и `join_media.py` через list-argv `QProcess`;
  пути не склеиваются в shell-команду. `--overwrite` появляется только после
  отдельного подтверждения, после чего коллизию повторно проверяет CLI.
- Без `--overwrite` итог публикуется атомарным no-replace rename на Windows
  (включая FAT/exFAT) или create-if-absent hard link на POSIX; файл,
  появившийся во время рендера, сохраняется и приводит к отказу. С
  подтверждённым разрешением используется `os.replace`.
- Выбранные FFmpeg/FFprobe являются исполняемым доверенным кодом. GUI не
  подхватывает автоматически локальные бинарники вне PATH и предупреждает
  пользователя выбирать только доверенные сборки.
- Объём отображаемого журнала ограничен; сохраняется диагностически полезный
  хвост вместо неограниченного роста памяти.
- До реализации process-tree cancellation GUI блокирует закрытие активного
  окна и не выдаёт остановку только родительского процесса за безопасную отмену.

## Возобновление и кэш

Если эта возможность реализована, запись связывается с идентичностью входов,
параметрами экспорта и совместимой версией инструментов. Повреждённая,
неполная или устаревшая запись отвергается. Значения из неё не используются как
команды и не дают права перезаписывать результат.

## Проверки перед выпуском

Обязательны отрицательные сценарии из `docs/TESTING.md`, в особенности странные
имена файлов, повреждённые медиа, коллизия результата, ошибки прав, прерванный
рендер и подменённый кэш. Упакованная Windows-версия считается готовой только
после smoke-теста на чистой машине без неявной зависимости от локальных путей
разработчика.
