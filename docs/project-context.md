# Контекст проекта

Video Chronicle — Python-проект для обработки и сборки медиахронологии с GUI, CLI и FFmpeg-интеграцией. `join_media.py` является текущей эталонной реализацией; проектные документы и stage-контекст находятся в `docs/` и `prompts/STAGES.md`.

Каталог `ffmpeg1/` рассматривается как локальная зависимость проекта; его содержимое не изменялось в рамках governance-миграции.
