# Индекс спецификаций

Спецификации описывают наблюдаемое поведение продукта. Статус каждой SPEC
определяет обязательность требований: черновик служит основой для обсуждения и
не является утверждённым контрактом. Сведения о текущей реализации приведены
отдельно и не превращают будущие цели в реализованные возможности.

| Уровень | SPEC | Статус |
| --- | --- | --- |
| Система | [Системные инварианты](system.spec.md) | Утверждённый baseline |
| Feature | [Timeline Builder](features/timeline-builder.spec.md) | Черновик; срез GUI-001 утверждён |
