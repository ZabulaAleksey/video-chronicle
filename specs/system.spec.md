# Системная спецификация Video Chronicle

- Статус: утверждённые системные инварианты и реализованный baseline
- Версия: 0.1
- Feature SPEC: `specs/features/timeline-builder.spec.md`

## 1. Назначение и область

Video Chronicle — локальное приложение для анализа, нормализации и объединения
фото и видео в MP4. Этот документ фиксирует стабильные системные инварианты.
Целевое пользовательское поведение Timeline Builder, включая ещё не
реализованные функции, задаёт feature SPEC.

## 2. Системные требования

- **SYS-FR-001 — Legacy CLI.** `join_media.py` принимает локальную папку,
  параметры инструментов и экспорта, обрабатывает поддерживаемые медиа и
  возвращает наблюдаемый код завершения.
- **SYS-FR-002 — Desktop entry point.** Default PySide6 GUI вызывает те же
  application services, что CLI, через worker thread, не копируя
  медиаконвейер. Legacy CLI через неблокирующий `QProcess` остаётся явным
  диагностическим fallback.
- **SYS-FR-003 — Коллизия результата.** Существующий или появившийся во время
  работы результат не заменяется без явного разрешения пользователя.
- **SYS-FR-004 — Диагностика.** CLI и GUI показывают причину критического
  сбоя; ошибки отдельных медиа допускают частичный успех, если хотя бы один
  элемент успешно обработан.
- **SYS-NFR-001 — Неизменность источников.** Исходные медиа используются
  только для чтения и не являются целью временной или финальной записи.
- **SYS-NFR-002 — Совместимость путей.** Пользовательские пути передаются как
  отдельные argv-элементы и поддерживают пробелы и Unicode в пределах ОС и
  внешних инструментов.
- **SYS-NFR-003 — Отзывчивость GUI.** Длительная медиаработа не выполняется в
  UI-потоке.
- **SYS-SEC-001 — Запуск внешнего кода.** Python, FFmpeg и FFprobe запускаются
  без shell-интерпретации; пользователь выбирает только доверенные сборки.
- **SYS-SEC-002 — Финализация.** Незавершённый файл остаётся во временной
  рабочей области. Публикация выполняется атомарно: no-replace без разрешения
  либо replace после явного разрешения.
- **SYS-COMP-001 — Совместимость.** Внутреннее развитие не меняет
  документированный CLI-контракт без отдельной миграции и обновления SPEC.

## 3. Ошибки и граничные случаи

- отсутствующая, пустая или недоступная входная папка;
- неподдерживаемые и повреждённые медиа;
- отсутствующие FFmpeg/FFprobe или недоверенно выбранный executable;
- одинаковые, отсутствующие, конфликтующие и timezone-aware даты;
- пути с пробелами, кавычками и Unicode;
- коллизия до запуска и во время финализации;
- нехватка места, отказ прав и аварийное завершение процесса;
- попытка закрыть GUI во время работы до появления безопасной отмены.

## 4. Критерии приёмки

- **SYS-AC-001 (SYS-FR-001, SYS-COMP-001).** Characterization-набор фиксирует
  CLI-аргументы, сортировку, ключевые ошибки и правила публикации.
- **SYS-AC-002 (SYS-FR-002, SYS-NFR-002, SYS-SEC-001).** Default GUI выполняет
  application plan/export вне UI thread; fallback передаёт executable и
  аргументы раздельно. Оба пути корректно отображают UTF-8 и не используют
  shell.
- **SYS-AC-003 (SYS-FR-003, SYS-SEC-002).** Поздняя коллизия без overwrite
  сохраняет появившийся файл; подтверждённый overwrite публикует только
  завершённый результат.
- **SYS-AC-004 (SYS-FR-004).** Ненулевой exit, crash, failed start и отсутствие
  нового результата после exit 0 отображаются как ошибка.
- **SYS-AC-005 (SYS-NFR-001).** Smoke-набор подтверждает отсутствие изменений
  входов при успешной обработке, пропуске и критическом сбое.
